🕌 Mosque Management System (Finance Tracker)

A premium, offline-first desktop application designed for mosques to manage donations, expenses, and employee payroll with multi-language support (English & Urdu) and advanced security features.

✨ Features

  • 💰 Donation Management: Track General, Zakat, Sadqa, and Construction donations with ease.
  • 📝 Expense Tracking: Record electricity, gas, water, maintenance, and other expenses.
  • 📊 Interactive Dashboard: Real-time summary of total donations, expenses, and net balance.
  • 📄 Monthly Reports: Generate and print detailed financial reports as text files.
  • 👥 Employee Management: Add and manage employees (Imams, Moazzins, etc.) and process monthly salary payments.
  • 🌐 Multi-Language Support: Seamlessly toggle between English and Urdu (Nastaleeq font) with a single click.
  • 🔒 Advanced Security:
    • Startup Lock: Requires a password immediately upon opening.
    • Auto-Lock: Automatically locks the application after 10 minutes of inactivity.
    • Password Management: Change passwords directly from the settings.
  • 💾 Data Integrity:
    • Offline-first with SQLite3.
    • Soft-delete functionality for all transactions.
    • Backup and Restore system to safeguard your data.

🚀 Getting Started

Prerequisites

  • Python 3.7+
  • CustomTkinter
  • sqlite3 (usually included with Python)

Installation

  1. Clone the repository: 
    git clone https://github.com/salmanasmat/mosque-management.git
cd mosque-management
  2. Install dependencies: 
    pip install customtkinter
  3. Run the application: 
    python mosque_app.py
